2. HOW REVIEWER APPROVES / REJECTS A REPORT (STEP-BY-STEP)
================================================================================

[METHOD 1: Directly from Test Sessions Table]
1. Log in as Reviewer:
   - Username : `reviewer1`
   - Password : `Reviewer@123`
2. Navigate to "Test Sessions" page (http://localhost:5173/sessions).
3. Use the "Filter Status" dropdown and select "Under Review" (or "Draft" / "In Progress").
4. In the Actions column on the right, Reviewers and Admins see green "Approve" and red "Reject" buttons.
5. Click "Approve":
   - The status changes instantly to "APPROVED".
   - The status badge turns green with a checkmark.
6. Click "PDF" or "DOCX" button to download the official approved certificate.

[METHOD 2: From inside the Test Wizard]
1. Log in as `reviewer1` / `Reviewer@123`.
2. Open any session by clicking "Enter Data / Wizard".
3. Review the observation tables (Span, Eccentricity, Repeatability, Discrimination, Safety).
4. In the top-right header bar, click the green "Approve Report" button.
5. A confirmation notification confirms approval, and status changes to "APPROVED".

6. COMPLETE ROLE-BY-ROLE TESTING WALKTHROUGH
================================================================================

--------------------------------------------------------------------------------
ROLE 1: LAB TECHNICIAN (Username: tech1 / Password: Tech@123)
--------------------------------------------------------------------------------
1. Log in at http://localhost:5173 as `tech1`.
2. Go to "Test Sessions" -> Click "+ New Test Session".
3. Select an instrument and click "Start Session & Launch Wizard".
4. Fill in the test readings from Section 5 and click "Save Observations".
5. Click "Run Final Compliance Check" (Status becomes `UNDER_REVIEW`).

--------------------------------------------------------------------------------
ROLE 2: METROLOGY REVIEWER (Username: reviewer1 / Password: Reviewer@123)
--------------------------------------------------------------------------------
1. Log in at http://localhost:5173 as `reviewer1`.
2. Go to "Test Sessions" page.
3. Locate the session submitted by the Lab Technician (`UNDER_REVIEW`).
4. Click the green "Approve" button directly in the table (OR open the Test Wizard and click "Approve Report" in the top bar).
5. The session status changes to `APPROVED`.
6. Click "PDF" or "DOCX" to download official report certificates signed by the Reviewer.

--------------------------------------------------------------------------------
ROLE 3: CHIEF ADMIN (Username: admin / Password: Admin@123)
--------------------------------------------------------------------------------
1. Log in at http://localhost:5173 as `admin`.
2. View real-time system metrics, session breakdown, and approval rates on the Dashboard.
3. Add Manufacturers, Register Instruments, and Manage Users.
4. Admins also have full approval and override permissions for any session.

--------------------------------------------------------------------------------
ROLE 4: PUBLIC INSPECTOR / VIEWER (Username: viewer1 / Password: Viewer@123)
--------------------------------------------------------------------------------
1. Log in as `viewer1`.
2. Read-only access to search instruments, inspect session compliance, and verify certificates without modification rights.
