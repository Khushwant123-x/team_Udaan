SLIDE 1 / SECTION 1: PROJECT IDENTITY & EXECUTIVE SUMMARY
================================================================================

- Project Title      : Government-Grade NAWI Type Evaluation & Standardized Test Report Generator
- SIH Problem        : SIH Problem Statement 26035
- Target Ministry    : Department of Consumer Affairs, Legal Metrology Division, 
                       Ministry of Consumer Affairs, Food & Public Distribution, Govt of India.
- Testing Laboratory : National Physical Laboratory (NPL) / Regional Reference Standards Laboratories (RRSL)
- Standard Complied  : OIML Recommendation R 76-1:2006 & OIML R 76-2 (Test Report Format)

Executive Summary:
------------------
Legal Metrology officers verify weighing instruments (balances, commercial scales, weighbridges) 
before they enter public trade or legal use. This web application automates manual metrological 
calculations, enforces strict OIML R 76 MPE error thresholds, maintains tamper-proof audit trails, 
and generates official PDF certificates & editable Word DOCX reports with a single click.

  - PDF Generator   : ReportLab 4.x (Tamper-proof official Govt certificate with header & signature block)

SLIDE 5 / SECTION 5: OIML R 76-1 MATHEMATICAL CALCULATIONS & MPE FORMULAS
================================================================================

Scale Interval Parameter:
-------------------------
Load 'm' is evaluated in terms of scale interval 'e' (where load_in_e = m / e).

OIML R 76-1 Table 6 Initial Verification MPE Limits:

1. CLASS I (Special Accuracy - Fine Balances):
   - 0 <= m/e <= 50,000      ==> MPE = ± 0.5 e
   - 50,000 < m/e <= 200,000 ==> MPE = ± 1.0 e
   - m/e > 200,000           ==> MPE = ± 1.5 e

2. CLASS II (High Accuracy - Lab Balances):
   - 0 <= m/e <= 5,000       ==> MPE = ± 0.5 e
   - 5,000 < m/e <= 20,000   ==> MPE = ± 1.0 e
   - 20,000 < m/e <= 100,000 ==> MPE = ± 1.5 e

3. CLASS III (Medium Accuracy - Commercial Scales & Weighbridges):
   - 0 <= m/e <= 500         ==> MPE = ± 0.5 e
   - 500 < m/e <= 2,000      ==> MPE = ± 1.0 e
   - 2,000 < m/e <= 10,000   ==> MPE = ± 1.5 e

4. CLASS IIII (Ordinary Accuracy - Industrial Bulk Scales):
   - 0 <= m/e <= 50          ==> MPE = ± 0.5 e
   - 50 < m/e <= 200         ==> MPE = ± 1.0 e
   - 200 < m/e <= 1,000      ==> MPE = ± 1.5 e

Evaluation Math Equations:
--------------------------
1. Indication Error (E) : E = Indication - Load  (or E = Indication + 0.5e - Delta_L - Load)
2. Repeatability Diff   : Difference = Max(Readings) - Min(Readings) <= MPE
3. Eccentricity Test    : Tested at 5 platform positions using 1/3 Max load
4. Discrimination Test  : Adding 1.4e extra load must cause display change of >= 1.0e

SLIDE 6 / SECTION 6: DATABASE DOMAIN ENTITIES & SCHEMAS
================================================================================

1. User Entity (`users` table):
   - id, username, email, full_name, hashed_password, role (ADMIN/LAB_TECHNICIAN/REVIEWER/VIEWER), lab_code, created_at

2. Manufacturer Entity (`manufacturers` table):
   - id, name, code, address, contact_person, email, phone, country, license_number, created_at

3. Instrument Entity (`instruments` table):
   - id, manufacturer_id, model_name, serial_number, accuracy_class (CLASS_I/II/III/IIII), max_capacity, min_capacity, verification_scale_interval (e), actual_scale_interval (d), unit, temperature_min, temperature_max

4. Test Session Entity (`test_sessions` table):
   - id, session_code, instrument_id, technician_id, reviewer_id, status (DRAFT/IN_PROGRESS/UNDER_REVIEW/APPROVED/REJECTED), test_date, temperature_c, humidity_percent, pressure_hpa, overall_pass

5. Test Observation Entity (`test_observations` table):
   - id, session_id, test_type (SPAN/ECCENTRICITY/REPEATABILITY/DISCRIMINATION/SAFETY), raw_data_json, evaluated_data_json, is_passed

6. Audit Log Entity (`audit_logs` table):
   - id, user_id, action, resource, details_json, ip_address, timestamp
